# Tic Tac Toe

A simple web-based Tic Tac Toe game built using HTML, CSS, and JavaScript. Play against a friend in Two Player Mode or challenge the computer in Single Player Mode.

---

## 🌐 Live Demo

View the project here: https://Praneeth5607.github.io/Tic-Tac-Toe/

---

## Features

* Single Player Mode (vs Computer)
* Two Player Mode
* Winner Detection
* Draw Detection
* Game Reset Functionality
* Interactive User Interface
* Responsive Design

---

## Logic Used

* Players take turns placing X and O on a 3×3 grid
* Winning combinations are checked after every move
* The game ends when:

  * A player completes a winning pattern
  * All cells are filled resulting in a draw
* In Single Player Mode, the computer automatically selects an available cell
