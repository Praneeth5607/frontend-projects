# DailyBasket

A simple and interactive grocery shopping frontend website built using HTML, CSS, and JavaScript. Users can browse products, add items to the cart, remove items from the cart, and view the total price instantly.

---

## Live Demo

View the project here:  
https://Praneeth5607.github.io/dailybasket/

---

## Features

- Product listing section
- Add products to cart
- Remove products from cart
- Dynamic total price calculation
- Cart data stored using LocalStorage
- Sticky cart section
- Hover effects and interactive UI
- Clean and modern interface

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- LocalStorage API
- Font Awesome Icons
