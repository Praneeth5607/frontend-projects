# 🌦️ Weather Forecast Dashboard

A modern and responsive weather dashboard built using HTML, CSS, and JavaScript. The application provides real-time weather information, air quality data, sunrise/sunset timings, hourly forecasts, and a 5-day weather forecast using the OpenWeather APIs.

## 🌐 Live Demo

Try the project here:

**https://Praneeth5607.github.io/frontend-projects/weather-forecast-dashboard/**

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Current temperature
- 🌤️ Weather description
- 📅 Live date and time
- 🌅 Sunrise and sunset timings
- 💧 Humidity
- 🌬️ Air pressure
- 🌡️ Feels like temperature
- 👁️ Visibility
- 🌫️ Air Quality Index (CO, SO₂, O₃, NO₂)
- 🕒 Today's weather forecast
- 📅 Upcoming 5-day weather forecast
- ❌ Error popup for invalid city names
- 📱 Responsive and modern UI

## 🚀 APIs Used

### Current Weather API

Provides:
- Temperature
- Humidity
- Pressure
- Visibility
- Sunrise & Sunset
- Weather Description

### Air Pollution API

Provides:
- CO
- SO₂
- O₃
- NO₂

### 5-Day Forecast API

Provides:
- Today's forecast
- Next 5 days forecast

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Praneeth5607/weather-forecast-dashboard.git
```

2. Open the project folder

3. Replace the API key in `script.js`

```javascript
const key = "YOUR_API_KEY";
```

4. Open `index.html` in your browser.
